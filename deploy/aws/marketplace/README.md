# AWS Marketplace Assets

This directory contains the non-code documents and checklists required to submit the Pinner.xyz S3 Server AMI + CloudFormation product to AWS Marketplace.

- `USAGE_INSTRUCTIONS.md` — buyer-facing post-deployment instructions.
- `SECURITY_GROUPS.md` — recommended inbound/outbound rules and security guidance.
- `SUBMISSION_CHECKLIST.md` — pre-submission and post-submission verification list.

For the technical deployment files, see the parent `deploy/aws/` directory.
